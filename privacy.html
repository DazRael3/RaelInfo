Privacy Notice

This page describes the data behavior of the RaelInfo static website included in this package. The site operator must review it against the actual hosting configuration, legal entity, third-party services and applicable law. This template is not legal advice.

1. Calculator inputs

Calculations run in the visitor's browser. This static version does not intentionally transmit calculator balances, income, debt amounts or other calculator inputs to a RaelInfo server. Do not enter sensitive information on a shared or public device.

2. Local browser storage

RaelInfo can store calculator values and display preferences in the browser's local storage so a visitor can return to a scenario. This data is not encrypted by the application, is not synced between devices and may be accessible to anyone with access to the browser profile. The JSON export feature creates a file on the visitor's device. Visitors should protect exported files as they would other personal financial records. A clear-data control is provided in the application.

3. Public data services

The website requests indicative crypto-market data from CoinLore and daily USD/CAD reference-rate data from Frankfurter. Those requests do not include the amounts entered in calculators. The providers and network infrastructure may process technical connection information (such as IP address, request metadata and user-agent data) under their own policies.

  • CoinLore API documentation
  • Frankfurter API documentation

4. Cookies, analytics and advertising

The supplied application does not include an analytics provider, advertising pixel, behavioral advertising cookie, account system or marketing email platform by default. Browser local storage is used for preferences and optional saved scenarios. If the operator adds analytics, advertising, chat, embedded content, forms, accounts or other integrations, this notice must be updated and any legally required consent must be obtained.

5. Affiliate links

No affiliate offers are configured by default in this build. If the operator adds affiliate or sponsored links, the relevant placement must disclose the material connection clearly and conspicuously. Third-party destinations may use their own cookies and tracking technologies under their own privacy notices.

6. Hosting and security logs

The hosting provider may collect technical server logs, security telemetry, IP addresses and request metadata. The operator must update this section to identify the actual host, retention practices and any additional processors used by the deployed site.

7. Retention and deletion

Calculator scenario data stored in local storage remains on the visitor's device until removed by the visitor or browser. Visitors can use the application's clear-data control or their browser's site-data controls. The operator does not receive a cloud copy of a saved scenario in this static version.

8. Children

The site is intended as a general financial-information resource and is not designed to collect personal information from children. The operator should adapt this section if the intended audience or features change.

9. Operator and contact

Before launch, replace this sentence with the operator's legal name and a monitored privacy contact email/address. Also identify the applicable jurisdiction and any required privacy representative.

10. Changes

This notice should be updated whenever the site's data practices, integrations, hosting, or legal obligations change. Display the actual effective date after review.
