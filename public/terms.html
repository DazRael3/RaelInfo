1. Educational use only

RaelInfo provides general educational calculators, reference information and tools. It does not provide personalized financial, investment, securities, tax, accounting, legal, mortgage, credit or other professional advice. No result is a recommendation, quote, offer, guarantee or promise of future performance.

2. Estimates and assumptions

Results depend on user-entered values and simplified assumptions. Actual payments, costs, interest, rates, eligibility, tax treatment and outcomes can differ. Some tools omit fees, taxes, insurance, transaction costs, lender rules and individual circumstances. Users should independently verify assumptions and important information before acting.

3. Crypto market data

Crypto data is obtained from CoinLore's public API through the RaelInfo server and is indicative aggregated market information. It may be delayed, incomplete, unavailable or different from prices available on a trading platform. It is not an executable bid, ask or transaction quote. Cryptocurrency is volatile and can result in substantial or total loss.

4. Stock quotes, news and SEC filings

Stock quote data is available only when the operator has configured a supported provider and an API key. Provider rate limits, quote delays, asset coverage and display/redistribution rights depend on the selected provider and account plan. News article metadata is retrieved from GDELT and links to original publishers. SEC filing metadata is retrieved from SEC EDGAR; the service is rate-limited and subject to SEC fair-access requirements. Always review source timestamps and original documents.

5. Currency data

USD/CAD data is obtained from Frankfurter as a daily reference rate. It is not an intraday trading price or a rate offered by a bank, card network, broker or remittance provider. Provider fees and spreads may change the amount received in an actual transaction.

6. Canadian registered-account reference

The TFSA/RRSP tool provides an annual-limit reference and simplified RRSP new-room estimate using user-entered prior-year earned income and an annual dollar maximum. It does not calculate personal available contribution room. Carry-forward room, withdrawals, pension adjustments and other CRA rules are not fully modeled. Verify actual room in CRA records and current official guidance before contributing. Over-contributions may have tax consequences.

Links to public data services and third-party websites are provided for convenience. RaelInfo does not control their availability, data, products, fees, security or terms. Visitors are responsible for reviewing third-party terms before using an external service.

No affiliate offers are configured by default in this build. If the operator adds affiliate or sponsored links, RaelInfo may earn compensation for qualifying clicks, sign-ups or purchases. A clear, conspicuous disclosure must appear close to each relevant recommendation. Compensation does not establish suitability, quality or endorsement.

9. Accounts and portfolio storage

Optional accounts require a username and password. Passwords are stored as scrypt hashes, not plaintext. The application uses a same-site HttpOnly session cookie. Portfolio positions are stored in the server file database. The current JSON database is intended for a single-server, low-volume installation; it is not a bank, brokerage ledger, encrypted financial vault or enterprise database. Users should use a unique password and should not rely on this feature as their sole financial record. An account and its positions can be permanently deleted from the dashboard after password confirmation.

10. Local storage

Calculator scenario saving uses local browser storage; it is not encrypted or synchronized with the account portfolio. Users are responsible for protecting their browser profile and exported JSON files, especially on shared devices.
